## I. TEMEL KONSEPİ

### Platform Danışmanlık Modeli (3 Tier)

```
TIER 1: KENDİ EXPERT TEAM (Platform'un Danışmanları)
├─ 24/7 AI Helpdesk (SMS/WhatsApp, hızlı cevap)
├─ Automated Monitoring Alerts (uydu, hastalık, sulama)
└─ Standart FMIS Modülleri (Agro, Soil, Monitor, Livestock)
   Revenue: Premium Subscription ($50-100/çiftçi/yıl)

TIER 2: COMMUNITY EXPERT CONSULTANTS (YENİ - Bu Doküman)
├─ Ziraat Mühendisleri, Agronomistler Freelance Danışmanlık
├─ Proje Bazlı Hizmet ("Hassas tarıma geçiş", "Toprak restorasyonu" vb.)
├─ Özel Durum Analizi (1-on-1, Video Konsultasyon, On-Site Ziyaret)
└─ Community Rating & Reputation System
   Revenue: Platform 25-30% Komis (Consultant 70-75% alır)

TIER 3: B2B KURUMSAL DANIŞMANLIK (Gelecek Faz)
├─ Gıda şirketi ile entegre danışmanlık (supply chain optimization)
├─ Devlet programları (tarım politikası danışmanlığı)
└─ Üniversite-Platform araştırma ortaklığı
   Revenue: High-value contracts (toplu danışmanlık)
```

     → Geçerse: "Verified Expert" badge
     → Başarısız olursa: Feedback + improve için hakkı

──────────────────────────────────────
Proje sırasında:
  ├─ Milestone completion tracking
  ├─ Automated alerts:
  │  "Koçak son 3 gün iş güncellemesi yok" → Çiftçiye not
  ├─ Mid-point check-in (Hafta 2-3):
  │  Platform: "Koçak nasıl gidiyor?"
  │  Çiftçi: "Çok iyi, zamanında" / "Sorun var"
  └─ Final review before payment release

QA LAYER 3: FARMER FEEDBACK
────────────────────────────
Proje bitişinde:
  ├─ Multi-dimensional rating (Technical, Communication, etc.)
  ├─ Open-ended comment box:
     "Danışman hakkında başka neler söylemek ister misiniz?"
  ├─ Video testimonial (optional):
     "Koçak'ın danışmanlığının sonucu ne oldu?"
  └─ Follow-up (30 gün sonra):
     "Danışman önerisi uygulandı mı? Sonuç ne?"

QA LAYER 4: PEER REVIEW (Diğer Danışmanlar)
──────────────────────────────────────────
Belli aralıklarla (aylık):
  ├─ Platform: Top 10 danışman'ı davet eder
  │  "Arkadaşlarınız hakkında peer review yapın"
  ├─ Danışman: Bir diğer danışmanın çalışmasını inceliyor
  │  "Koray'ın toprak analizi yöntemi doğru mu? 4.5/5"
  └─ Anonimity: İsim gizli kalabilir
     (Küçük danışman topluluğunda conflict of interest engellemek)

QA LAYER 5: COMMUNITY FORUM
──────────────────────────

  ├─ Çiftçi: "Koçak'ın önerisi işe yaradı mı?"

  ├─ Danışman (Koçak): "Evet, burada niye işe yaradığını açıklıyorum"
  └─ Knowledge sharing:
     "Bu tip problem için genel solution nedir?"
     (Platform AI: Similar cases otomatik öner)

QA LAYER 6: AUTOMATED CHURN DETECTION
──────────────────────────────────────
Platform algoritması:
  ├─ Red flags:
  │  ├─ Rating suddenly drops (4.8 → 3.2)
  │  ├─ Çiftçi şikayetleri artıyor
  │  ├─ Project completion rate < 70%
  │  ├─ Response time > 24 saat trend
  │  └─ Multiple disputes in 3 months
  │
  ├─ Automated Action:
  │  "Koçak, ratinginiz düşüş gösterdi. Niye oldu?
  │   Destek gerekirse, Platform mentorship programı var"
  │
  └─ Suspension Threshold:
     "Rating < 3.0 veya 5+ disputes → 30 gün suspension
      (Refund + improvement şansı)"
